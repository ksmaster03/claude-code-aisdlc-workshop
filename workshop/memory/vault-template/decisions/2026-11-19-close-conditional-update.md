# ปิดงานซ่อมด้วยคำสั่งเดียวแบบมีเงื่อนไข แล้วเช็คจำนวนแถว

## ปัญหา
ช่างสองคนกดปิดงานเดียวกันได้ในเวลาใกล้กัน ถ้าโหลดงานมาเช็คสถานะก่อนแล้วค่อยบันทึก งานอาจถูกปิดซ้อน

## ตัดสินใจ
ใช้ `ExecuteUpdateAsync` ที่มีเงื่อนไขสถานะอยู่ใน `Where` แล้วเช็คจำนวนแถวที่เปลี่ยน ถ้าได้ 0 ให้หยุดทันทีพร้อมบอกเหตุผล

## เหตุผล
- เช็คสถานะกับบันทึกเกิดในคำสั่งเดียว จึงไม่มีช่องว่างให้อีกคนแทรก
- จำนวนแถวบอกได้ชัดว่าปิดสำเร็จหรือมีคนปิดไปก่อนแล้ว

## ทางที่ไม่เลือก
- โหลด entity มาเช็คแล้ว `SaveChanges`: มีช่องว่างระหว่างอ่านกับเขียน
