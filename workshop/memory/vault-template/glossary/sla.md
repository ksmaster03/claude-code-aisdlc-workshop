# SLA งานซ่อม

## แปลว่า
เวลาที่ต้องปิดงานซ่อมให้เสร็จ นับจากเวลาที่แจ้งงาน แยกตามระดับความรุนแรง

| ระดับ | ความหมาย | ต้องปิดภายใน |
|---|---|---|
| P1 | เครื่องหยุด ไลน์ผลิตไม่ได้ | 4 ชั่วโมง |
| P2 | ผลิตได้แต่ช้าลงหรือของเสียเพิ่ม | 24 ชั่วโมง |
| P3 | ไม่กระทบการผลิตตอนนี้ | 72 ชั่วโมง |

- นับชั่วโมงตามปฏิทินต่อเนื่อง รวมกลางคืนและวันหยุด
- ปิดตรงเวลากำหนดพอดีถือว่าทัน ช้ากว่านั้นแม้หนึ่งนาทีถือว่าเกิน
- งานที่เกินต้องแจ้งหัวหน้าแผนกครั้งเดียวต่อเหตุการณ์
