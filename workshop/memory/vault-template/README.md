# แม่แบบ vault ความจำภายนอก (แลบ LM)

โฟลเดอร์นี้คือ vault ตั้งต้น เป็นไฟล์ Markdown ธรรมดา Claude Code อ่านและเขียนได้เลย เปิดดูด้วย Obsidian ได้ แต่ไม่จำเป็น

## วิธีใช้

1. คัดลอกทั้งโฟลเดอร์ไปไว้ในที่เก็บไฟล์ที่บริษัทอนุมัติ แล้วเปลี่ยนชื่อเป็น `claude-vault`
   - Google Drive for desktop: `G:\My Drive\claude-vault` (G: คือตัวอักษรไดรฟ์เริ่มต้น เครื่องคุณอาจต่างได้)
   - OneDrive ของบริษัท: `%OneDrive%\claude-vault`
   - ไม่มีทั้งสองอย่าง: `%USERPROFILE%\claude-vault` (อยู่เครื่องเดียว ไม่ซิงก์)
2. ใน repo OpsTrack สร้าง `.claude/settings.local.json` จาก `setup/settings-local-snippet.json` (แก้ path ให้ตรง)
3. สร้าง `CLAUDE.local.md` ที่ราก repo จาก `setup/claude-local-snippet.md` (แก้ path ให้ตรง)
4. เพิ่มสองบรรทัดนี้ใน `.git/info/exclude` กันสองไฟล์ส่วนตัวหลุดเข้า commit
   ```
   CLAUDE.local.md
   .claude/settings.local.json
   ```
5. เปิดแชตใหม่ แล้วถามว่า "อ่าน index.md ใน vault แล้วบอกว่ามีโน้ตอะไรบ้าง"

## โครงสร้าง

| ที่อยู่ | เก็บอะไร |
|---|---|
| `index.md` | สารบัญและกติกาการจด อ่านก่อนเสมอ |
| `templates/` | แม่แบบ 4 ชนิด: decision, gotcha, glossary, howto |
| `decisions/` | การตัดสินใจพร้อมเหตุผล |
| `gotchas/` | เรื่องที่พลาดบ่อยและวิธีแก้ |
| `glossary/` | ศัพท์ของทีม |
| `howto/` | ขั้นตอนที่ทำซ้ำ |
| `setup/` | ข้อความตั้งค่าสำหรับคัดลอก ไม่ใช่ความจำ |

โน้ตที่มี tag `example` เป็นตัวอย่าง ลบทิ้งได้

## ข้อห้าม

- ห้ามเก็บคีย์ รหัสผ่าน URL ลับ ข้อมูลลูกค้า หรือข้อมูลส่วนบุคคล
- ห้ามวางใน drive ส่วนตัว ใช้เฉพาะที่เก็บที่บริษัทอนุมัติ
- ชื่อไฟล์และโฟลเดอร์ใช้ภาษาอังกฤษ เนื้อหาเป็นภาษาไทยได้
- สองคนอย่าแก้โน้ตเดียวกันพร้อมกัน ที่เก็บไฟล์อาจสร้างสำเนาซ้อนขึ้นมา ให้แยกโน้ตตามเรื่องแทน
