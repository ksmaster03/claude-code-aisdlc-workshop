# สารบัญความจำ: OpsTrack

vault นี้คือความจำภายนอกของงาน OpsTrack ทั้งคนและ Claude อ่านหน้านี้ก่อนเริ่มงาน แล้วเปิดโน้ตที่เกี่ยวข้องตามลิงก์

## กติกาการจด (Claude ต้องทำตาม)

1. หนึ่งโน้ต หนึ่งเรื่อง ชื่อไฟล์เป็นภาษาอังกฤษตัวเล็ก คั่นด้วยขีด เช่น `2026-11-19-close-conditional-update.md`
2. เริ่มจากแม่แบบใน `templates/` ทุกโน้ตต้องมี frontmatter `type` `date` `tags` `source`
3. เก็บโน้ตตามชนิด: `decisions/` `gotchas/` `glossary/` `howto/`
4. เพิ่มลิงก์ของโน้ตใหม่ในหน้านี้ ใต้หัวข้อที่ตรงชนิด พร้อมคำอธิบายหนึ่งบรรทัด
5. ลิงก์ไปโน้ตที่เกี่ยวข้องด้วย `[[ชื่อไฟล์]]` (ไม่ต้องใส่ .md)
6. ข้อเท็จจริงเปลี่ยน ให้แก้โน้ตเดิมแล้วเปลี่ยน `date` อย่าสร้างโน้ตซ้ำ
7. ห้ามจดคีย์ รหัสผ่าน URL ลับ ชื่อลูกค้า หรือข้อมูลส่วนบุคคล
8. เสนอเนื้อหาให้คนอ่านก่อนทุกครั้ง แล้วค่อยเขียนลงไฟล์
