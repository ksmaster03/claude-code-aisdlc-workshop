# REQ-101 ข้อความต้นฉบับ

จาก: คุณสมชาย หัวหน้าไลน์ SMT-2 · ถึง: ทีมระบบ · เรื่อง: ขอเพิ่มเรื่องปิดงานซ่อม

"ตอนนี้ช่างปิดงานในระบบแล้วไม่มีใครรู้ว่าเครื่องเสียเพราะอะไร อยากให้ปิดงานจากหน้าเว็บได้เลยและต้องใส่สาเหตุทุกครั้ง ถ้างานไหนเกิน SLA ให้เด้งเตือนหัวหน้าแผนกด้วย ช่างบางคนปิดงานแทนกันเองซึ่งไม่ควร และอยากรู้ด้วยว่าเครื่องไหนเสียบ่อย ๆ ขอด่วนก่อนสิ้นเดือนนะครับ เพราะ audit จะมาตรวจ"
