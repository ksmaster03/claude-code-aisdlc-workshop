# นโยบาย SLA งานซ่อม

ใช้กับงานแจ้งซ่อมทุกงานใน OpsTrack (ฉบับใช้งาน 1 มี.ค. 2569)

## เวลาที่ต้องปิดงาน

| ระดับ | ความหมาย | ต้องปิดงานภายใน |
|---|---|---|
| P1 | เครื่องหยุด ไลน์ผลิตไม่ได้ | 4 ชั่วโมง |
| P2 | ผลิตได้แต่ช้าลงหรือของเสียเพิ่ม | 24 ชั่วโมง |
| P3 | ไม่กระทบการผลิตตอนนี้ | 72 ชั่วโมง |

## วิธีนับ

- นับเป็นชั่วโมงตามปฏิทิน ต่อเนื่องทั้งกลางวันกลางคืนและวันหยุด เริ่มจากเวลาที่แจ้งงาน (`CreatedAt`)
- กำหนดเสร็จ = เวลาแจ้ง + เวลาตามระดับ
- ปิดงานตรงเวลากำหนดพอดีถือว่าทัน ปิดหลังจากนั้นแม้หนึ่งนาทีถือว่าเกิน SLA
- เวลาทั้งหมดเป็นเวลาท้องถิ่นของโรงงาน

ในโค้ด กติกานี้อยู่ที่ `src/OpsTrack.Business/Sla/SlaCalculator.cs` ที่เดียว

## เมื่องานเกิน SLA

- ระบบต้องแจ้งหัวหน้าแผนกของไลน์นั้น ผ่าน webhook แจ้งเตือนของโรงงาน (ค่า `Notification:WebhookUrl`)
- งานที่เกิน SLA ต้องแสดงให้เห็นในหน้ารายการงาน
- งานหนึ่งงานต้องแจ้งเตือนไม่เกินหนึ่งครั้งต่อเหตุการณ์ ห้ามแจ้งซ้ำ
