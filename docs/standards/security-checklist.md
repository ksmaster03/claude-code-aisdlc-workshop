# Security checklist สำหรับ PR

ผู้รีวิวต้องไล่ครบทุกข้อ ข้อไหนไม่เกี่ยวกับ PR ให้เขียนว่า "ไม่เกี่ยว" ข้อไหนตรวจไม่ได้ให้เขียนว่า "ไม่ได้ตรวจ" พร้อมเหตุผล

## SEC-1 SQL injection

- ห้ามสร้าง SQL ด้วยการต่อ string หรือ string interpolation ที่ไม่ได้ส่งเป็นพารามิเตอร์ (`FromSqlRaw($"... {x}")` ถือว่าผิด)
- ค่าจาก query string, body, header ต้องเข้า SQL ทางพารามิเตอร์เท่านั้น

## SEC-2 สิทธิ์ (authorization)

- endpoint ที่แก้ข้อมูลทุกตัวต้องมี `[RequireRole(...)]`
- endpoint ที่ส่งออกหรือดาวน์โหลดข้อมูล (export) ต้องเป็น `Supervisor` เท่านั้น
- ถ้า business rule กำหนดเจ้าของงาน (เช่น ช่างที่รับงานเท่านั้นที่ปิดงานได้) ต้องตรวจใน service ไม่ใช่ซ่อนปุ่มในหน้าเว็บอย่างเดียว

## SEC-3 ความลับ (secrets)

- ห้ามมี key, token, รหัสผ่าน, connection string ที่มีรหัสผ่าน อยู่ในโค้ดหรือ `appsettings*.json` ที่ commit
- อ่านค่าจาก configuration (ตัวแปรแวดล้อม, user-secrets, Key Vault) เท่านั้น
- ถ้าเผลอ commit ไปแล้ว ถือว่าค่านั้นรั่ว ต้องเปลี่ยนค่าใหม่ ลบออกจากโค้ดอย่างเดียวไม่พอ

## SEC-4 ตรวจ input

- ตรวจทุกค่าที่รับจากภายนอกด้วย `Guard` ที่ service
- วันที่รับเป็นรูปแบบ `yyyy-MM-dd` ช่วงวันที่ต้องบอกให้ชัดว่ารวมวันสุดท้ายหรือไม่
- จำกัดความยาวข้อความและจำนวนแถวที่ขอได้

## SEC-5 ไฟล์ CSV และ Excel

- ทุกช่องที่มี `,` `"` หรือขึ้นบรรทัดใหม่ ต้องครอบด้วย `"` และเปลี่ยน `"` ข้างในเป็น `""` (RFC 4180)
- ช่องที่ขึ้นต้นด้วย `=` `+` `-` `@` (รวม tab และ carriage return) ต้องใส่ `'` นำหน้า กัน formula injection เวลาเปิดใน Excel
- เขียนเป็น UTF-8 พร้อม BOM เพื่อให้ Excel อ่านภาษาไทยถูก

## SEC-6 การจัดการข้อผิดพลาด

- ห้ามกลืน exception (catch ว่าง หรือ catch แล้วตอบ 200 พร้อมข้อมูลว่าง)
- ห้ามส่ง stack trace หรือข้อความภายในให้ผู้ใช้ ให้ใช้ problem details
- error ที่ผู้ใช้แก้เองได้ต้องตอบ 4xx พร้อมข้อความที่เข้าใจได้

## SEC-7 ข้อมูลส่วนบุคคลใน log

- log ได้แค่ชื่อผู้ใช้ ห้าม log เบอร์โทร อีเมล token หรือเนื้อหาไฟล์ที่ส่งออก
- `EnableSensitiveDataLogging` ห้ามเปิดถาวรบนเครื่องจริง

## SEC-8 ขีดจำกัดทรัพยากร

- รายการผ่าน API ไม่เกิน 500 แถวต่อหน้า การ export ไม่เกิน 10,000 แถวต่อครั้ง
- `HttpClient` ที่เรียกออกภายนอกต้องมี timeout
