# หลักฐานจากเครื่องจริง (bug 103)

ไฟล์ในโฟลเดอร์นี้เก็บมาจากเหตุการณ์ "รายงานสรุปว่างเปล่าบนเครื่องจริง" เช้าวันที่ 12 พ.ย. 2569

| ไฟล์ | มาจากไหน |
|---|---|
| `server.log` | log ของ OpsTrack บนเครื่อง OPS-APP-01 IT เปิด `Diagnostics:LogSqlParameters=true` และ log SQL ระดับ Information ชั่วคราว แล้วรีสตาร์ตบริการตอน 08:30 |
| `browser-console.log` | console ของ Chrome บนเครื่องคุณสมชาย (กด F12 แล้วบันทึก console) |
| `network.json` | แท็บ Network ของ Chrome ส่งออกเป็น HAR เฉพาะคำขอรายงานสรุป |

ทั้งสามไฟล์เป็นช่วงเวลาเดียวกัน เวลาใน `network.json` เป็น UTC ส่วนเวลาใน log ฝั่งเซิร์ฟเวอร์เป็นเวลาเครื่อง (UTC+7)

ข้อมูลในไฟล์เป็นข้อมูลจำลองสำหรับฝึก ไม่ใช่ log จริงของโรงงานใด
